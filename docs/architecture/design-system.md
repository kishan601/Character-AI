# Visual Design System & Transparency Engine

The Aegis interface is built around custom AMOLED dark surfaces with dynamic wallpaper exposure controls.

## Design Tokens
- **Background**: #0a0907 (Deepest Obsidian)
- **Surfaces**: gba(18, 14, 11, var(--transparency-alpha))
- **Accent Glow**: #e06738 (Amber Core) / #f0894a (Warm Highlight)
- **Conversation Surface**: High-contrast translucent grey cards (g-dark-900/85) to guarantee readable text against complex wallpaper graphics.
- **Dynamic Controls**: 0–100 wallpaper transparency slider and full Zen mode toggle.
